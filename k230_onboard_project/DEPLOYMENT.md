# K230部署清单

## 📁 文件部署结构

请按照以下目录结构上传文件到K230的`/data`分区：

```
/data/
├── web_main.py              ← 主程序（启动这个）
├── web_server.py            ← HTTP服务器模块
├── stream_handler.py        ← MJPEG视频流模块
├── yolo_controller.py       ← YOLO控制器
├── detection_manager.py     ← 检测记录管理
├── wifi_config.py           ← WiFi配置（需修改WiFi信息）
├── config.json              ← 配置文件
├── model.kmodel             ← YOLO模型文件
├── detections/              ← 检测记录保存目录（程序自动创建）
└── static/                  ← Web前端文件目录
    ├── index.html           ← 网页主页
    └── app.js               ← JavaScript脚本
```

## ⚙️ 配置步骤

### 1. 修改WiFi配置

编辑 `/data/wifi_config.py`：

```python
# 在文件末尾找到这两行，修改为你的WiFi信息
WIFI_SSID = "你的WiFi名称"
WIFI_PASSWORD = "你的WiFi密码"
```

### 2. 确认文件路径

确保Web前端文件在正确位置：
- `/data/static/index.html`
- `/data/static/app.js`

### 3. 确认模型文件

确保YOLO模型在正确位置：
- `/data/model.kmodel`

## 🚀 启动程序

在K230上运行：

```python
cd /data
python web_main.py
```

或在CanMV IDE中打开`web_main.py`并运行。

## ⚠️ 常见问题

### 1. WiFi连接失败
- 检查WiFi名称和密码是否正确
- 确保K230和路由器距离不要太远
- 确认WiFi是2.4G频段（K230可能不支持5G）

### 2. 浏览器无法访问
- 确认电脑/手机与K230在同一WiFi网络
- 检查IP地址是否输入正确
- 确认端口号是8080
- 检查防火墙设置

### 3. 页面加载失败
- 确认`/data/static/`目录下有`index.html`和`app.js`
- 查看K230终端输出的错误信息
- 检查文件权限

### 4. 视频流不显示
- 先点击"启动摄像头"按钮
- 确认摄像头已正确连接
- 检查模型文件路径是否正确

## 📝 调试技巧

查看详细日志：
- K230终端会输出所有HTTP请求
- 格式：`请求: GET /path`
- 如果看到`新连接: (IP, 端口)`说明浏览器已连接

## 🔄 重启程序

如需重启：
1. 在K230终端按 `Ctrl+C` 停止程序
2. 重新运行 `python web_main.py`
